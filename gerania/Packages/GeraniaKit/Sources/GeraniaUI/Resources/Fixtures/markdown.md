# Разметка в панели

Панель показывает ответ **потоком**: текст приходит по частям и появляется сразу.

- Пункт списка
- Второй пункт
- Третий пункт

> Короткая цитата тоже поддерживается.

Обычный текст с *курсивом*, `моноширинным фрагментом` и [ссылкой](https://example.com).

---

Разделитель отделяет законченный блок от следующего.
